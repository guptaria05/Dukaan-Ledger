# Roadmap

## Implemented web features
- Responsive dashboard and mobile navigation.
- Today, month-to-date and year-to-date revenue summaries.
- Year/month/day revenue breakdown chart.
- Product inventory with custom categories, cost and default selling prices.
- Sale-level selling price override with sale-time inventory cost snapshot.
- Opening stock and dated stock movements.
- Monthly item additions and weekly / overall inventory CSV downloads.
- Customer-wise item breakdown, sales, payments and outstanding dues.
- Customer created dates and last-month new-customer view/export.
- Vendor directory and vendor-wise purchase register.
- Seasonal plans with month windows and linked products.
- Expenses and estimated net-profit report.
- Browser-local persistence.

## Next milestones
1. Add data export/import and full backup/restore for all records.
2. Add authentication and a secure hosted database.
3. Add multi-device sync and multiple shop support.
4. Add edit/delete flows, purchase returns, sales returns and invoice printing.
5. Add dated stocktake reconciliation and scheduled weekly reminders.
6. Add staff roles, audit log, reporting filters and automated end-to-end tests.
